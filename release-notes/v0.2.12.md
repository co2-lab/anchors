# v0.2.12

- **Three gates stop charging a whole-project pass to one target.** On a copy of a project's repository, a check of three changed specs took 298 s, most of it in three gates that each spent their run on a single target: `nav-reachable` 56 s, `symbol-exists` 50 s, `docs-covered` 13 s.
  - The map's neighbours were found by scanning every edge on each call, which made walking the screens quadratic. They are now read through an index of where each node's edges are, built once for the slice of edges and checked at each read, so a sort in place or a rename builds it again. (GRQRG)
  - `symbol-exists` read and scanned every code and test file on every run. Each file's names are now kept between runs, by the file's revision in the map, in the repository's common git folder, shared by its worktrees. A new revision, a file with changes not committed, or another comment syntax reads the file again. (SYMXS)

  The same check now takes 74 s: `nav-reachable` 2 s, `symbol-exists` 1.3 s once its names are kept, `docs-covered` 4.4 s.
