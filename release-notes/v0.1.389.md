# v0.1.389

- **A gate's legacy can end: `legacy.until`.** `legacy:` softens a gate for the targets last changed before a date, and until now it did so forever. `until: <date>` is its deadline: from that day on no target is legacy, and every one answers with the gate's own severity. Before it, a verdict the legacy softened says until when, and what it will do after. A new gate can now bar the new code at once and the old code from a date on, instead of leaving the old code pending without end. (GTENG-B37, CNFGO-B77, CNFGO-E13)

  ```yaml
  - name: mutation-score
    blocking: true
    legacy:
      before: 2026-10-21
      until: 2026-12-15
      severity: {fail: inform}
  ```

  An `until` that is no date, or does not come after `before`, refuses the configuration.
