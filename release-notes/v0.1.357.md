## `section-required`: a dependency on types only no longer calls for a section

By default, `when: {depends_on_layer: [...]}` now counts only dependencies on a layer's
values. A component that only imports a layer's types (`@dep[type]`) receives its data some
other way, so it no longer triggers the requirement. Measured at MIF, this was the case for
22 of 36 charges.

To count type imports too, add `kinds`:

```yaml
when: {depends_on_layer: [hook, store], kinds: [value, type]}
```

The map now records the kind of a `depends-on` edge: `kind: type` when the target's types
are its only import. Older binaries ignore the field.

Everything in the v0.1.351 notes still applies: run `anchors migrate` once, crossing format 8.
