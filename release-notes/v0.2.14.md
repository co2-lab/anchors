# v0.2.14

- **A typed `each` table is read.** The TS family's test pattern read `it.each(table)` but not `it.each<Kind>(table)`: a typed table's rows read as never run, and `examples-match` failed on them. A project that copied the pattern into its `anchors.yaml` updates it to the new one. (DLCTI)
- **A test changed outside the index says so.** In the commit hook `evidence-fresh` judges the staged version, while the test run measured the working copy. When the test or a file it depends on has changes outside the index, running the test again does not help, and the message said only to run it again. It now names those files and says to stage the change or stash it. The hook lists the changes outside the index once per run. (EVFRV, GTMTG)
