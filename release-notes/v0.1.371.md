## Docs in the project's language, orphan pages removed, and a calmer progress view

**The progress shows detail only where something is moving.** A settled demand is one that
is all done, or that has none of its tasks started and none in progress.

- **`progress summary` and the monitor** print a settled demand as one line, without its
  stages.
- **`progress show`**, for the whole file, prints a settled demand as its heading only,
  without its stages or tasks.
- **What keeps everything:** `progress show <demand>` still details that demand, and the
  file and `--json` still keep everything.

**`docs build` removes the pages its templates no longer produce.** A page in `docs/` whose
generated marker names a template of `doct/` that is gone is removed, along with any folder
left empty, and the build lists each removal. This covers renamed templates and deleted
ones.

- A page without the marker is never touched.
- A page listed in `docs.keep` is never touched either. The list takes globs relative to
  `docs/`, for pages generated once and kept by hand since:

  ```yaml
  docs:
    keep: ["guides/**"]
  ```
- `--dry-run` lists what it would remove and removes nothing.

**The layer page's summary note follows the project's language.** It used to be in
Portuguese whatever `lang:` said.

**This repository's docs are now in English**: `architecture.md`, `behavior.md`, `rules.md`
and `layers/gate.md`. `docs init` already scaffolds in the project's language. A project
whose templates predate that can delete them and run `docs init` again, and the next build
removes the old pages.

Everything in the v0.1.351 notes still applies: run `anchors migrate` once, crossing format 8.
