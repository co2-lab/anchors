# v0.2.19

- **A release changelog past GitHub's limit is cut instead of refused.** A product's first tagged release follows no tag, so its changelog is the whole history. GitHub refuses a Release body over 125000 characters, and the stage was recorded as failed after its tag had already been written. The body is now cut at the last whole line that fits, followed by a line saying how many lines were left out. A stage that failed this way can be run again: the tag is already on its sha, so only the missing Release is written. (RLSTA-B04)
