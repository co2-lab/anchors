# v0.2.5

- **A listing skips the keys that are not versions.** A release policy may keep a `default` entry beside its versions, which the project's code falls back to; `released:` read it as a version and `fresh` failed with `"default" is not a semver version`. A listing takes `skip:`, the keys of its map that are not versions (`released: { file: …, keys: …, where: { … }, skip: [default] }`), and a requirement's `listed:` read from `released:`'s file inherits it. Keys are skipped by name only: a mistyped version would otherwise vanish unseen. Without `skip:`, the error now points to it. (VRSNN, VRQRA)

To use `skip:`, install this binary first: an older one refuses the key.
