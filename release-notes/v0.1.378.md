## Fix: a name with accents gives a code of letters

`anchors code` and `anchors new` compress a unit's name into its code letter by letter, and read
the name byte by byte: "Resposta à proposta" gave `R` followed by half of the `à`, a code that is no
code (reported from SS, which writes its specs in Portuguese).

A name's letters are now taken without their accents (`à` → `a`, `ç` → `c`), and any other character
outside A–Z and 0–9 ends a word. "Resposta à proposta" gives the code of "Resposta a proposta". Codes
already in headers do not change: only new ones are generated.

Everything in the v0.1.351 notes still applies: run `anchors migrate` once, crossing format 8.
