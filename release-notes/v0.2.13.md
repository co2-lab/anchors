# v0.2.13

- **A budget, selection or retry run takes coverage only where it is whole.** v0.2.11 kept a partial run's coverage to its impact path for `anchors test --changed`; the other partial runs still took the whole report. A budget batch runs some test files and measures every code file in part, and a retry under load reruns some tests. They now hand their batches to the ingestion too: a batch of test files takes no code file's coverage, and a selection's batch takes the coverage of the code files it names, whose related tests all ran. (BDGRN, NGSTI)
