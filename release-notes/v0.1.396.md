# v0.1.396

- **`anchors map deps <unit> --flat`: a unit's dependency closure as paths, one per line.** The tree `map deps` prints, down or with `--up` up, within `--depth`, as sorted paths with the file itself included — the shape a project's script reads to cross a handler's closure with the environment it reads, the tables it touches or the grants it needs. From MIF's P12: five released defects were wiring (an env var, a table or a secret not granted to the handler that reached it through a dependency). (MDCMP-B04)
- `test_bypass:` (v0.1.395) is documented on the anchors.yaml page and in `anchors guide test`.
