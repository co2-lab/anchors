## Fix: mock doubles of another workspace's modules are measured again

v0.1.351 lost doubles whose specifier uses an alias the project declares for a different
workspace. For example, `@/lib/x` in `apps/landing-page`, with `@/` declared for
`apps/mobile/`. `mock-typed` and `mock-stamped` took them for third-party modules and stopped
measuring them, without saying so.

Now, when the aliased path is not a file of the map, the tail after the alias's prefix is
matched by its suffix.

### New: aliases scoped per workspace

`dialect.import_resolve.scoped` declares aliases that hold only for the importers a glob
matches. Use it for each workspace's own tsconfig `paths`:

```yaml
dialect:
  import_resolve:
    aliases: {"@/": "apps/mobile/"}
    scoped:
      - files: 'apps/landing-page/**'
        aliases: {"@/": "apps/landing-page/src/"}
```

An importer's scoped aliases win over the global ones for the same prefix.

Everything in the v0.1.351 notes still applies: run `anchors migrate` once, crossing format 8.
