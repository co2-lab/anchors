## Fix: a stage's last job is `anchors pipeline record`

shellcheck, run on every workflow by actionlint, read `anchors pipeline done <stage>` as the end
of a shell loop and reported SC1010 on each workflow that calls it (MIF).

The command that runs a stage's `verify:` and records its outcome is now `anchors pipeline
record <stage>`. `done` stays as an alias, so a workflow already written with it still runs. The
`pipeline-wired` gate reads `record`, `done` and `run` as a stage's record.

Everything in the v0.1.351 notes still applies: run `anchors migrate` once, crossing format 8.
