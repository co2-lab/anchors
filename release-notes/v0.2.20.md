# v0.2.20

- **A waiver says what it spared.** A waiver restricted to a target (`[skip-<gate>@<CODE>: reason]`) used to skip the gate on that target, and the report said only "waived". The gate now runs on the waived target too. When the target fails, the result is a skip that gives the waiver's reason and what it spared. When it passes, the pass stands. (GTENG-B40, GTENG-B41)
- **A waiver that spared nothing is said.** After the report, the check names each waiver that spared nothing: either the target it names passed without it, or the check confronted no target with that code. A waiver written for every failing target, with a reason that fits few of them, now shows up instead of hiding the target that broke. The notice informs and blocks nothing. (CGPCH-B102)
