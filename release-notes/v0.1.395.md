- **`test_bypass:` and the gate `bypass-proven`: a path the code skips while a test runs is run by a suite that reaches it.** From MIF-1S: a hook returned early under `EXPO_PUBLIC_E2E`, the unit tests doubled the write, the end-to-end skipped it, and nothing ran it. The project declares how a bypass is recognised and which suite layers run the skipped path; a code file with a bypass asks a test of its own that passed in one of them, or `@no-bypass-proof: <reason>` on the bypass's line or the line above. Informative, in the catalog; asks nothing until `test_bypass:` is declared. (TBYSA, BYPRS)

  ```yaml
  test_bypass:
    patterns:
      - "process\\.env\\.EXPO_PUBLIC_E2E === 'true'\\)\\s*return"
    proven_by: [integration]
  ```
