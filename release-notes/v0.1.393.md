# v0.1.393

- **Navigation gates in a repository of several apps: a shared screen name names this app's screen.** `nav-annotated`, `nav-matches-spec`, `nav-symmetric` and `nav-reachable` indexed screens by name and route across the whole repository, one screen per name, so when two apps shared a screen's name (`ProfileScreen`, `HelpSupportScreen`…) every Out row, flag and In of one app resolved to the other's, and failed. A name or route several screens share now names the one nearest the file that cites it — the screen sharing the longest folder with it. A screen's code in a Destination (`` `BSPRB` ``) names that screen wherever it is, and an entry route names every screen it fits, so each app enters at its own. Reported by SS (apps/ss and apps/ss-business). (NCGNV-B09)

Everything in the v0.1.351 notes still applies: run `anchors migrate` once, crossing format 8.
