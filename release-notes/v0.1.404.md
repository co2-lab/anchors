# v0.1.404

- **In a git worktree, the pre-commit defers to the commit-msg as in the main tree.** The pre-commit looked for the commit-msg under `$(git rev-parse --git-dir)/hooks`. In a worktree that is `.git/worktrees/<name>`, which has no `hooks/`. The pre-commit concluded there was no commit-msg and blocked at once, so a `[skip-<gate>@<CODE>: why]` in the message was never read. It now looks where git runs hooks from (`git rev-parse --git-path hooks`, which follows worktrees and `core.hooksPath`), and so does `pre-commit.d`. Reported by MIF. (INHKN-B19)

  **Run `anchors install-hooks --force`** to get the new pre-commit.

Everything in the v0.1.351 notes still applies: run `anchors migrate` once, crossing format 8.
