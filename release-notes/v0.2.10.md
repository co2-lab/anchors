# v0.2.10

- **The commit hook asks git once.** A project's pre-commit of 8 files ran `updated-at-atual` over 853 targets for 32 s: over the index, each target asked `git diff --cached` alone, one git process per file. The staged files are now listed once per run, and each question answered from the list. (GTMTG)
- **The last-commit dates are read once per HEAD.** They came from a log of the whole history on every run — 4.7 s of that pre-commit. They are kept per HEAD in the repository's common git folder, shared by its worktrees; a new HEAD reads the log again, and a shallow clone keeps nothing, since its history deepens under the same HEAD. (GTMTG)
