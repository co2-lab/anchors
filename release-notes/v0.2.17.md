# v0.2.17

- **Reports from another working copy keep each other's proof.** A JUnit report outside the repository was kept under its file name alone. When a project's worktrees live outside the repository and each workspace writes a report with the same name, the second report ingested erased the scenario proofs of the first, and `scenario-coverage` failed with the tests green. A report inside another working copy (a worktree or a clone) is now kept under its path in that copy; a report outside any working copy keeps its file name. (NGSTI-B24, #1)
