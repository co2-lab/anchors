# v0.1.402

- **`push_review.require_gates` — a waiver in a commit message frees the commit, not the push.** With it, the pre-push hook runs the blocking gates a commit or a push charges over what the pushed commits reach. Every file is read as the pushed tip holds it, and no `[skip-<gate>@<CODE>: why]` from a commit message counts. Each failure refuses the push naming the gate, the target and the pushed commit whose message waived it. An edit not yet committed is not what the push sends, and does not count. A waiver meant to reach the remote goes in the artifact (`@no-*`), which the gate reads. It works with or without `required` and `require_judgment`. Requested by MIF. (PRCMS-B09, PSRSA-B01, RPSCR-B62)

  ```yaml
  push_review:
    require_gates: true
  ```
