# v0.2.18

- **A file the commit does not hold no longer blocks testid-consistent.** In the commit hook the gate lists a spec's consumer folders on disk and reads them through the git index. An untracked file in one of them, such as a new visual baseline that the layers count as a test, is not in the index, and its absence was reported as "could not be read". Every spec in the folder was then pending, and the commit was blocked. Such a file is now left out. Only a file the index holds and that fails to read still leaves the gate pending. (TICTS-B31)
