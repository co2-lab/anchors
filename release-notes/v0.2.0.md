# v0.2.0

- **A new start for the repository.** The history of this repository was restarted from a single commit. The command line behaves as it did in v0.1.422: nothing a project declares in `anchors.yaml` changes, and the format of the map stays 8.
- **Every release before v0.2.0 is retracted.** `go.mod` retracts `[v0.0.0, v0.1.422]`, and those releases are no longer published here. A project whose `min_version` names one of them, or whose pipeline downloads one by its tag, moves to `min_version: 0.2.0`.
- **The design notes left the repository.** The `DESIGN-*.md` and `FINDINGS-*.md` files were working notes, not part of the product, and the references to them were removed from the code, the specs and the site.
