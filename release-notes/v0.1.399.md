# v0.1.399

- **A block comment inside a line of code no longer stales the file's proofs.** The comment was blanked in place, so `load(a /* ARSCA-S04 */)` read as `load(a` followed by spaces and `)`, the evidence revision moved, and every proof of the file had to run again. It now leaves the line as if never written: it goes out with the blank before it when a blank, a closer or the end of the line follows, and with the blank after it when an opener precedes it. A whole-line comment and a comment at a line's end were already left out. Reported by MIF while marking rules in code. (RPSCR-B61)

Everything in the v0.1.351 notes still applies: run `anchors migrate` once, crossing format 8.
