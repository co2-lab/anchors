# v0.2.7

- **A list inside `any:` is a path with its own requirements.** A stage reached by two paths asked one version requirement of both: a production release that takes what passed review, or a hotfix, blocked every hotfix with `same_as_passed: review-release`. A list of requirements holds when all of them do, so each path of an `any:` asks its own:

  ```yaml
  - any:
      - [{ passed: review-release }, { version: { same_as_passed: review-release } }]
      - [{ from: "hotfix/*" }, { version: { fresh: true } }]
  ```

  A refusal names why each path failed; an empty list refuses the configuration. (PCSPP, PCSPA)

To write a list as a requirement, install this binary first: an older one refuses it.
