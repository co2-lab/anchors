# v0.2.2

- **A stage asks of the version its sha carries.** A new requirement in a stage's `requires`, `version: { product, fresh, listed, same_as_passed, expected }`, is answered at the sha, never in the working tree. `fresh`: the version is above every release, the product's tags wherever they are reachable and what the product's new `released:` lists; a version still in review is not released, so resubmitting it passes. `listed: { where: {...} }`: a file gives the version an entry with those fields, by default the file and map `released:` declares. `same_as_passed: <stage>`: the version is the one the commit that passed that stage carried, so production releases what passed review. `expected`: the version is the one the branch's strategy computes; `manual` asks it be fresh, and `none` refuses. (VRQRA, PCSPP)
- **A stage asks that the fixes came back.** `contains: <branch>` fetches that branch from `origin` and holds when its head is an ancestor of the sha; when it is not, it names how many commits are missing and the first five. (VRQRA)
- **A branch may bound its versions.** A rule of `versioning.<product>.branches` takes `range:`, an explicit range (`1.0.x`) or `from_base`, the release the branch was cut from at its last part. Every `version:` requirement and `anchors version bump` refuse a version outside it, and `anchors version` shows it. (VRSNN, VRSNI)
- **`released:` lists releases the tags do not record.** A file, the map whose keys are versions, and the fields an entry must hold, for the releases made before the project wrote tags. (VRSNN)
- **`anchors branch check` confronts the pull request's head.** Besides the flow, it answers the `version:` and `contains:` requirements of every stage of the base, on the head commit (`--head-sha`, or the event's `pull_request.head.sha`), so a refusal shows on the pull request and not later in the stage. `same_as_passed` stays with the stage. (BCSBR)

The tags must be in the CI's checkout (`fetch-depth: 0`) for `fresh` and `range:` to see them. To use the new keys, install this binary first: an older one refuses them.
