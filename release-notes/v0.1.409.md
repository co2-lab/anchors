# v0.1.409

- **`check` and `verify` refuse positional arguments.** In `anchors check --changed a b c`, the flag takes `a`, and the shell passes `b` and `c` as positional arguments. The command accepted them and dropped them, then judged `a` alone and answered that every gate passed. In MIF, 1 of 1728 files was judged, and the check read green. Both commands now fail before judging anything. The error names the arguments and the two ways to list files: one per flag (`--changed a --changed b`), or a comma-separated list (`--changed a,b,c`). Reported by MIF. (CGPCH-E09, VPFVR-E06)

Everything in the v0.1.351 notes still applies: run `anchors migrate` once, crossing format 8.
