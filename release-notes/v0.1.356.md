## Fix: `anchors coverage` agrees with the `scenario-coverage` gate

`anchors coverage` and `anchors report` now count a spec's requirements the way the
`scenario-coverage` gate does: only what the spec defines. In particular, they no longer
count as requirements:
- codes the spec only cites, such as handles listed in a Test IDs table;
- rules marked `@no-scenario`.

Before this fix, the coverage overview could show missing proof that the gate did not
report.

Everything in the v0.1.351 notes still applies: run `anchors migrate` once, crossing format 8.
