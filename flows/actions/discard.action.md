# Ação: `anchors discard` — tirar do quadro o que não faz mais sentido

> **Código**: `ACDIS`

O card sai do quadro — colunas, árvore, roadmap, faixa de pendências — e permanece no
GitHub com a razão registrada.

É para o que não faz mais sentido, NÃO para o que terminou: trabalho entregue se FECHA, e
o roadmap precisa dele para desenhar o passado. Descartar o que foi feito apagaria a
história.

## Comando

    anchors discard --card <n> --reason "<por quê>"
